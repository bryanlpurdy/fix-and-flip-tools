# Fix & Flip Tools

A web-based suite of tools for fix-and-flip real estate investors, built for internal use by [Blue Star Realty Group](https://bluestarrealtygroup.com).

## Tools

- **Hub** — Sign in once, then choose a tool.
- **Deal Analyzer** — Analyze acquisition costs, rehab budgets, financing, and expected profit on a flip.
- **Property Walkthrough** — Mobile-first repair estimator: walk a property, toggle items, attach photos, and save a shareable estimate to the cloud.

## Access

Available at [tools.bluestarrealtygroup.com](https://tools.bluestarrealtygroup.com). Requires an account to save data.
